### [IEJB Hub](https://github.com/kaiquednzz/iejb-hub)

**JavaScript • Vite • PostgreSQL • Supabase • Cloudflare • PWA**

A private web app, **live in production**, that runs the day-to-day of a church: worship team schedules, setlists, member management and the church's finances.

- **Schedules & setlists:** monthly roster in a few taps, push notifications only to who was affected, and a personal calendar feed (iPhone / Google).
- **Finance with real controls:** cash counts are confirmed by a second person through a **QR code with blind counting**, monthly summary with charts, full audit history.
- **Security by design:** every rule lives in the database (Row Level Security), CSP and security headers, leaked-password check, privacy policy.
- **Quality:** ~290 automated database checks run before every change; mobile first, desktop ready.
